## Dataset Overview
This collection contains six cancer datasets with varying sample sizes and feature dimensions.

## Available Datasets

### Cancer Real Data

#### 1. ALLAML.npz
- **Samples**: 72
- **Features**: 7,129
- **Features Type**: Numerical

#### 2. colon.npz
- **Samples**: 60
- **Features**: 2,000
- **Features Type**: Categorical

#### 3. GLI_85.npz
- **Samples**: 85
- **Features**: 22,283
- **Features Type**: Numerical

#### 4. leukemia.npz
- **Samples**: 72
- **Features**: 7,070
- **Features Type**: Categorical

#### 5. Prostate_GE.npz
- **Samples**: 102
- **Features**: 5,966
- **Features Type**: Numerical

#### 6. SMK_CAN_187.npz
- **Samples**: 187
- **Features**: 19,993
- **Features Type**: Numerical

## Data Structure

Each `.npz` file contains the following arrays:

### Core Data
- **`X`**: Feature matrix
- **`Y`**: Target variable

## Data Source 

The six cancer gene expression datasets are widely used as benchmark datasets for feature selection and are publicly available through dataset page: https://jundongl.github.io/scikit-feature/datasets.html
